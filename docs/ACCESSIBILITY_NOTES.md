# Accessibility Notes

The portfolio should remain usable with keyboard navigation, screen readers, and smaller screens.

## Practical checks

- Keep visible focus states.
- Use semantic buttons and links.
- Associate labels with form controls.
- Maintain readable contrast.
- Do not rely on color alone to communicate state.
- Provide useful alternative text for meaningful images.
- Keep interactive targets comfortably tappable on mobile.

Accessibility should be checked whenever navigation, forms, cards, or interactive effects change.
