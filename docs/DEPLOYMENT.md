# Deployment Notes

The portfolio is a static website and can be deployed from the repository root.

## Pre-deployment checklist

- Verify navigation links.
- Check project and certificate pages.
- Confirm the resume file opens correctly.
- Test the layout on mobile and desktop widths.
- Check images for broken paths.
- Remove development-only content before publishing.

## Static hosting

Any static hosting provider that serves the repository files can host the site. Configure the site root to the directory containing `index.html`.
