# Portfolio Performance Checklist

Use this checklist before publishing UI changes.

- Compress large images and use appropriate formats.
- Avoid loading scripts that are not required on the current page.
- Prefer lazy loading for below-the-fold images.
- Keep CSS and JavaScript focused on actual page requirements.
- Test the site on a slower mobile connection.
- Check that fonts and images do not cause visible layout shifts.
- Re-test navigation after optimization.

Performance improvements should preserve visual quality and accessibility.
