# Portfolio SEO Checklist

For each public page:

- Set a descriptive document title.
- Add a concise meta description.
- Use one clear primary heading.
- Use descriptive link text.
- Add meaningful alt text to informative images.
- Keep project descriptions specific and truthful.
- Verify canonical URLs when a page has multiple entry paths.
- Check that important content is accessible without client-side-only interactions.

The goal is discoverability without stuffing keywords into the portfolio.
