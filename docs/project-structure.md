# Portfolio Project Structure

This document records the intended organization of the portfolio project.

## Structure

- `src/` — application source code and reusable UI
- `public/` — static assets served directly
- `docs/` — project documentation
- Root configuration files — build, dependency, and tooling configuration

## Maintenance

Keep reusable sections/components separate from page-specific content. When adding a new portfolio section, update the navigation and verify desktop and mobile layouts before publishing.
